# Data Cleaning on the Titanic Dataset

A Python and Pandas data-cleaning project that turns the Titanic passenger dataset into a cleaner, analysis-ready dataset. The workflow is documented in a Jupyter Notebook.

## Project goals

- Inspect dataset shape, data types, missing values, and duplicate rows.
- Handle missing values using appropriate strategies.
- Standardize categorical values.
- Identify potential fare outliers using the interquartile range (IQR).
- Compare data-quality metrics before and after cleaning.
- Export the cleaned dataset to CSV.

## Tools

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook or Google Colab

## Files

- [DataCleaning.ipynb](DataCleaning.ipynb): step-by-step analysis and cleaning workflow.
- `Titanic-Dataset.csv`: expected source dataset. Place this file beside the notebook before running it.
- `Titanic_Cleaned.csv`: output generated by the notebook after successful execution.

## Run the notebook

1. Open `DataCleaning.ipynb` in Jupyter Notebook or upload it to Google Colab.
2. Make sure `Titanic-Dataset.csv` is available in the notebook's working directory.
3. Install the required packages if needed:

   ```bash
   python -m pip install pandas numpy matplotlib seaborn jupyter
   ```

4. Run the notebook cells from top to bottom.

## Cleaning decisions

| Field or check | Approach |
|---|---|
| `Age` | Fill missing values with the median |
| `Embarked` | Fill missing values with the mode, then expand port codes |
| `Cabin` | Drop the column because a large share of values is missing |
| Duplicate rows | Check and remove exact duplicates |
| `Sex` | Standardize capitalization |
| `Fare` | Detect outliers with the IQR rule and retain them for review |
| Data types | Inspect after cleaning |
| Output | Export the cleaned data as `Titanic_Cleaned.csv` |

Outliers are flagged rather than automatically deleted because unusually high fares may be valid observations.

## Notes

The notebook expects a local `Titanic-Dataset.csv` file. Make sure you obtain the dataset from a source you are permitted to use and place it in the working directory before running the notebook.
