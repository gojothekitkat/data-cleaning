# Data Cleaning on Titanic Dataset

## Objective
Demonstrate a systematic data-cleaning workflow by identifying and handling missing values, duplicates, inconsistent formatting, outliers, and data-type issues.

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Cleaning Steps
- Data quality report
- Missing-value analysis and treatment
- Duplicate detection and removal
- Categorical standardization
- IQR-based outlier detection
- Data-type verification
- Before-versus-after quality summary
- Export of the cleaned dataset

## Dataset
Titanic passenger dataset.
