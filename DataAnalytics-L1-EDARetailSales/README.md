# Exploratory Data Analysis on Retail Sales

## Objective
Perform Exploratory Data Analysis on a retail sales dataset to identify sales trends, customer behavior patterns, and actionable business insights.

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Analysis Included
- Dataset inspection and data quality checks
- Descriptive statistics
- Monthly and quarterly sales trends
- Customer age and gender analysis
- Revenue and sales volume by product category
- Correlation heatmap
- Age-group and gender spending analysis
- Business recommendations
