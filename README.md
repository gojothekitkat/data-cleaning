# Data Analytics Projects

This repository contains data analytics practice projects completed as part of the Oasis Infobyte internship tasks.

## Projects

### 1. Data Cleaning on the Titanic Dataset

A documented Python notebook that inspects data quality, handles missing values, standardizes categorical fields, checks duplicates, examines fare outliers using the IQR method, and exports a cleaned CSV.

- **Notebook:** [DataCleaning.ipynb](DataAnalytics-L1-DataCleaning/DataCleaning.ipynb)
- **Project README:** [Data Cleaning documentation](DataAnalytics-L1-DataCleaning/README.md)
